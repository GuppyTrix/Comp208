## References

1. **N. Wiener**, *Cybernetics: Or Control and Communication in the Animal and the Machine*. MIT Press, 2019.  
   - Informed the cybernetic feedback principles used in camera-driven error correction.

2. **A. Kamath**, “Lockdown Upgrades,” GitHub Pages, 2020.  
   - Referenced for practical microcontroller implementation and rapid prototyping approaches.

3. **B. Siciliano et al.**, *Robotics: Modelling, Planning and Control*. Springer, 2009.  
   - Provided mathematical grounding for proportional control and system error evaluation.

4. **R. A. Brooks**, “A robust layered control system for a mobile robot,” *IEEE Journal of Robotics and Automation*, 1986.  
   - Key influence on the behaviour-based state machine used by BRAB PUTT.

## Additional Notes

Behaviour-based robotics scoped the navigation system (Search, Detect, Track, Arrive).  
Cybernetic feedback loops were applied directly to camera error correction.
