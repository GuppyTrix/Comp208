# Comp208 Scrabbling Locomotion Robot
## Overview
This repository contains the code for an autonomous robot designed to navigate outdoor terrain and locate a drink can within a 15m² arena. The robot combines fully autonomous operation with remote control capability for handling unexpected situations.

## Project Purpose
The primary goal of this project is to create a robot that can:
- Autonomously navigate rough outdoor terrain, including: grass, mud, rotten apples, etc...
- Locate and approach a drink can within the arena
- Return to its starting position after completing the mission
- Provide status reporting and error logging capabilities
- Offer remote control override when autonomous mode encounters issues

## Key Features
### Autonomous Navigation
- Rough terrain locomotion system (considering alternatives to traditional wheels)
- Object detection and targeting system for locating drink cans
- Path planning and obstacle avoidance
- Automated return-to-home

### Operation Modes

1. \*\*Primary Autonomous Mode\*\*: Fully self-operating navigation and target acquisition
2. \*\*Secondary Remote Control\*\*: Manual override capability for troubleshooting

### Status Communication
- Real-time status reporting to users using LEDs and or buzzers

## Technical Considerations
### Terrain Adaptation
- Designed for chaotic and changing surfaces
- Movement optimized for grass, mud and rough terrain
- Waterproof design for different weather situations

### Communication Systems
- LEDs
- Buzzer
